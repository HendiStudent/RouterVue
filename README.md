Ini merupakan website tentang platform informasi dan transaksi terkait kelapa sawit di Indonesia. Website ini menyediakan fitur untuk menampilkan informasi sejarah, manfaat, produksi, jasa, dan jual beli. sistem ini utuk membantu masyarakat dan pelaku usaha kelapa sawit dalam mengakses informasi serta melakukan transaksi dengan lebih mudah. Berikut fitur yang tersedia dalam website Sawit Kita:
1. Login Admin
Untuk mengakses fitur khusus seperti Jual Beli, Jasa, dan Detail Pemesan.
2. Home
Menampilkan halaman utama website berisi logo, deskripsi platform, dan pengenalan umum.
3. Sejarah Kelapa Sawit
Menampilkan informasi sejarah perkembangan kelapa sawit di Indonesia dan dunia.
4. Manfaat Kelapa Sawit
Menjelaskan manfaat dan kegunaan kelapa sawit dalam berbagai bidang.
5. Produksi Kelapa Sawit
Menampilkan data dan informasi terkait proses produksi kelapa sawit.
6. Jual Beli Kelapa Sawit (khusus admin)
Fitur transaksi jual beli produk kelapa sawit.
7. Jasa Terkait Kelapa Sawit (khusus admin)
Menampilkan daftar jasa yang mendukung industri kelapa sawit.
8. Detail Pemesan (khusus admin)
Menampilkan data pemesan dari transaksi yang dilakukan pada sistem.
9. Logout
Fitur keluar dari akun admin untuk menjaga keamanan akses sistem.
